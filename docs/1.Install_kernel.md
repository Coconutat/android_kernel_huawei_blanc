# Installation Kernel Tutorial

Huawei has added image verification, which cannot be disabled by known methods.  
The only way is to install Magisk first and then install it using the `dd if= of=` format.   
Install Magisk is very easy.But **You need to find a way to extract RAMDISK.img from the device or firmware yourself.**   
Install KernelSU:  
Specific steps:  
```
adb push kernel.img /sdcard/Download/   // Assuming the compiled KSU kernel is named kernel.img
adb shell
su  // Grant shell su permissions within Magisk
cd /sdcard/Download/
dd if=kernel.img of=/dev/block/by-name/kernel // Replace the default kernel
```
Finally, uninstall Magisk.  
How to revert to the default kernel? Flash directly in Fastboot.  
But if you've compiled your own or use custom kernel, you'll need to do it this way.
