# How to compile the kernel
***
## Configuration Requirements

Due to the increased requirements of the EMUI10 kernel for compiling devices, I recommend high-end PC users to attempt it.  
Configuration requirements:  
Linux distribution: Ubuntu 22.04  
CPU: Recommend 4 cores  
RAM: Depending on the situation, **it is recommended to start with 16GB. 32GB is recommended**. (If it's a virtual machine, then simply double the memory and allocate the corresponding size.)  
SSD: 512GB is sufficient.  
Graphics card: Integrated graphics, discrete graphics, or higher.  

**Why such high memory requirements? Because Huawei has enabled `CONFIG_LTO` and `CONFIG_LTO_CLANG`.**  
You can disable these two compilation flags, but naturally, kernel optimization will worsen. The advantage is that the memory requirement for compilation becomes lower, and 8GB of memory is sufficient.  
Enabling compilation will be slow, and then memory usage will slowly expand to a maximum of about 29GB. Until compilation is complete.  
***

Compilation part:

## Requirements:  

+ Google's GCC, Clang cross-compilers  
   ```
   + [AArch64 Cross-compiler_Android 10 version](https://android.googlesource.com/platform/prebuilts/gcc/linux-x86/aarch64/aarch64-linux-android-4.9/+archive/84fb09fafc92a3d9b4d160f049d46c3c784cc941.tar.gz)  
   + [ARM Cross-compiler_Android 10 version](https://android.googlesource.com/platform/prebuilts/gcc/linux-x86/arm/arm-linux-androideabi-4.9/+archive/5a8beef7b1aa2c8ca0dfe4a00358559d12dfa3b6.tar.gz)  
   + [Google Clang_Android 10 version](https://android.googlesource.com/platform//prebuilts/clang/host/linux-x86/+archive/3f889f9c9d42bae85728fa89ba5f92a01704fd83.tar.gz)  
   ``` 
+ You can install ccache to increase compilation efficiency.    
  `sudo apt install ccache -y`  
+ Compilation commands:  
  ```
    // Cross-compiler path, fill in the actual path according to your own situation
    export PATH=$PATH:$(pwd)/../Compiler/Google/GCC64/bin:$(pwd)/../Compiler/Google/Clang/clang-r346389c/bin


    // Find those flag in Makefile!!!
    // Please find these two flags in Makefile!!! AOSP compilation flags, also cross-compiler paths, fill in the actual path according to your own situation
    export CLANG_PREBUILTS_PATH=$(pwd)/../Compiler/Google/Clang/clang-r346389c/
    export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:$(pwd)/../Compiler/Google/Clang/clang-r346389c/lib64/

    export CROSS_COMPILE=aarch64-linux-android-
    export ARCH=arm64

    make ARCH=arm64 O=out CC="ccache clang" merge_kirin970_ksu_defconfig
    // Define the number of compilation threads
    make ARCH=arm64 O=out CC="ccache clang" -j$(nproc --all)
  ```
